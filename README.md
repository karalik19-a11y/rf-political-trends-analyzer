# Аналитика по регионам РФ

Программа для карты регионов, новостей и данных по выборам.

---

## Как начать (три шага)

### 1. Python (один раз)

Скачайте и установите Python с сайта: https://www.python.org/downloads/

При установке **обязательно поставьте галочку** «Add python.exe to PATH» (добавить в PATH).

### 2. Скачать программу

На странице проекта нажмите зелёную кнопку **Code** → **Download ZIP**.

Распакуйте архив в любую папку (например, на Рабочий стол).

### 3. Запуск

Откройте папку и **дважды нажмите** файл:

**START.bat**

Подождите: при первом запуске всё настроится само (может занять несколько минут). Потом откроется окно в браузере — это и есть программа.

---

## Обновление

**Не удаляйте** папку с программой.

1. Откройте программу через **START.bat**
2. Слева нажмите **«Проверить обновление на GitHub»**
3. Если есть обновление — **«Скачать и установить»**
4. Закройте программу и снова нажмите **START.bat**

Либо просто дважды нажмите файл **UPDATE.bat** в той же папке.

Ваши сохранённые данные не пропадут.

---

## Сбор новостей

В программе слева: кнопка **«Собрать медиа + геопривязка»**.

Если новости не грузятся — иногда нужен VPN (часть сайтов в РФ недоступна).

---

## Если не запускается

- Установлен ли Python с галочкой PATH?
- Запускаете именно **START.bat**, а не другие файлы?
- Антивирус не блокирует окно?

При ошибке не закрывайте чёрное окно — там будет текст, что пошло не так.
